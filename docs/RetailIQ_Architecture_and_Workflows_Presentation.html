Core Architecture

Master System Architecture & Google Cloud Topology

Dual-tier web & mobile deployment featuring React 18 SPA on Firebase Hosting, Google Cloud Run FastAPI container (:8000), Cloud SQL PostgreSQL 17 system of record, and Google Vertex AI Enterprise Gemini 2.5 Flash gateway.

Client & Edge Tier

Deterministic Ledger Invariant

Enterprise Gemini AI Gateway

Shopper Intent, Fact Grounding & 15-Minute Reservation Hold

Shopper searches natural language prompt ("10,000 mAh USB-C under ₹1,500"). Gemini extracts hard factual constraints. When preferred SKU is stockout, system deterministically surfaces VoltGo Go (RQ002) with 15-min database row-lock hold.

Natural Language Extraction
Gemini 2.5 Flash normalizes unstructured conversational intent into typed criteria (10,000 mAh, USB-C, <₹1,500) matching product facts in the relational catalog.
Zero-Hallucination Substitute
Preferred VoltGo Pro is ATP 0 at Indiranagar (S1). VoltGo Go is verified in-stock (ATP 12, ₹1,299), showing side-by-side spec parity and preventing lost walk-outs.
Database Row-Locked Hold
Clicking "Reserve for 15 Minutes" acquires a database row lock and begins a real-time countdown timer (14:59). Order ORD-20261017-001 is placed with zero ghost inventory.
End-to-End Workflow 2

Store Associate Pickup & Atomic Stock Decrement

Customer arrives at Indiranagar (S1). Associate retrieves the reserved order, scans the physical unit barcode, and fulfills the pickup handover. On-hand inventory atomically decrements from 12 to 11 units.

Open Fullscreen Diagram ↗
Real-Time Queue Notification
The associate pickup queue instantly reflects the new reservation, customer name, and item location with complete operational transparency.
Physical Stock Mutation (12 ➔ 11)
Fulfillment executes an atomic database transaction: release reservation hold, increment fulfilled counter, and decrement physical on-hand stock from 12 to 11 units.
Immutable Cryptographic Audit
Every stock movement logs an immutable audit event with a SHA-256 state hash, timestamp, and actor identity, guaranteeing zero undetected shrinkage.
